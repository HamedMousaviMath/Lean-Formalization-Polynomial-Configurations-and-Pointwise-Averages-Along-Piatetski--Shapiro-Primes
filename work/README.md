# Historical implementation drafts

The files under `recurrence/` preserve substantial development work from the
recurrence milestone. They are historical drafts and diagnostic audit files,
outside the production library and its default build. Their earlier open
statuses are superseded by the checked implementations in `PSPrimes/`.

The final results, including the constructed finite-set iteration and the
literal length normalization, are described in `docs/PAPER_MAP.md`. Use
`docs/RESTART.md` for the current state and `evidence/VERIFICATION.md` for
the final commands and outcomes. No draft is used to fill a proof obligation
or to instantiate an external input.
